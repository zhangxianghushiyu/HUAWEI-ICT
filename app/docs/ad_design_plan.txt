 2.3 短剧激励视频
| 项目 | 内容 |
|:---|:---|
| 页面 | `pages/index/video-see.vue` |
| Placement ID | `b6a27695a5cd47` |
| 触发时机 | 用户点击「看广告解锁下一集」 |

- 位置：播放器下方或右上角

- 样式：金色渐变，突出「免费」

 五、开发规范要点
| 要点 | 说明 |
|:---|:---|
| 预加载 | 插屏和激励视频必须在展示前预加载 |
| 防重复 | 每个页面独立控制 `takuInitialized` 状态 |
| 降级 | 广告加载失败时 Toast 提示或直接跳过 |
| 频次 | 插屏广告至少间隔 2-3 个内容单元 |
| 复用 | 同一 Placement ID 可多页面共用，Taku 自动分配 |
