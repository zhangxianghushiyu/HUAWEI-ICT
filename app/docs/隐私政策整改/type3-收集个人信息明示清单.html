四、关于"基座启动阶段"信息获取的特别说明

本应用基于 DCloud（数字天堂）uni-app 5+ App 离线框架构建，其基座运行时（lib.5plus.base-release.aar）内置了 uni-ad 模块（io.dcloud.feature.gg），该模块会在 Activity onCreate 阶段自动执行"ba_pull"策略拉取，过程中会通过 MSA SDK 获取匿名 OAID。该行为发生在隐私弹窗展示之前，属于 DCloud 基座框架的底层机制：

1. 所获取 OAID 仅在本机以及广告/反作弊 SDK 网络请求中使用，不会写入您的账号档案，也不用于跨设备追踪；

2. 若您在隐私弹窗中选择"暂不同意"，本应用将立即退出，不会进入任何业务页面，也不会连接您本人的账号数据；

3. 若您希望完全阻止本行为，可选择卸载本应用，或在系统"设置 → 隐私 → 广告 ID"中重置或清除 OAID。

我们已就该行为向 DCloud 官方反馈并申请补丁；在补丁发布前，本清单如实披露该行为并说明其目的与最小必要性。
