二、共享规则说明

1. 我们仅在本清单及《隐私政策》声明的目的范围内与上述第三方 SDK 共享必要的最小范围个人信息；

2. 除 DCloud uni-ad 模块 和 MSA OAID SDK 在基座启动阶段自动初始化外，我们会在您同意《隐私政策》后才初始化其他 SDK 并允许其收集信息；两个基座 SDK 的初始化说明见《隐私政策》"启动初始化与 SDK 运行阶段说明"一节；

3. 我们不会向任何与本应用服务无关的第三方出售、出租或共享您的个人信息。
