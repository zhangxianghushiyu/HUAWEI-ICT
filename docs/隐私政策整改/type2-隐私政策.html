启动初始化与SDK运行阶段说明（重要）

本应用基于 DCloud（数字天堂）uni-app 5+ App 离线框架构建，框架内置的 uni-ad 模块（io.dcloud.feature.gg）会在 App 进程首次启动、Activity onCreate 阶段自动初始化，用于维持基座运行时（获取版本策略、内容分发通道、反作弊配置）。该初始化过程中会通过移动智能终端补充设备标识体系统一调用 SDK（MSA OAID SDK）获取匿名设备标识符 OAID（原始规范中亦称 CAID），用途仅限于：（1）基座服务完整性校验；（2）反作弊、反机刷、反异常行为检测；（3）后续广告展示的用户不重复计数。

该初始化过程与您是否点击"同意并继续"无关，属于 DCloud 基座框架的底层机制，本应用无法在保持功能完整的前提下将其推迟到隐私弹窗之后。若您不希望本应用完成上述启动初始化，请在隐私政策弹窗中选择"暂不同意"或直接关闭应用；应用将在您做出选择前不进入任何业务页面，也不会连接您本人的账号数据。所获取的 OAID 仅在本机及广告/反作弊 SDK 请求中使用，不会写入您的账号档案，亦不用于跨设备追踪。

除上述基座初始化 SDK 外，其他所有第三方 SDK（Taku、优量汇、百度广告、穿山甲、百度移动统计、火山引擎设备安全等）均严格在您点击"同意并继续"之后才初始化，具体清单见本政策第三节。

一、我们如何收集和使用您的个人信息

（一）您主动提供的信息

1. 账号注册与登录：当您注册、登录本应用时，我们会收集您的手机号码（用于发送验证码、验证身份、完成账号创建）；当您选择使用微信登录时，经您授权，我们会获取您的微信昵称、头像、OpenID等授权信息，用于绑定本应用账号。

2. 实名认证：当您使用提现功能（每月提现金额超过500元）时，为满足《非银行支付机构网络支付业务管理办法》及反洗钱相关规定，我们需要收集您的真实姓名和身份证件号码（身份证）。该等信息仅用于实名认证及支付合规目的。

3. 客服与反馈：当您联系客服或提交反馈时，我们会收集您主动填写的手机号码、问题描述、截图等信息。

（二）我们自动收集的信息

1. 设备信息：为识别您的设备并预防恶意程序及反作弊，提高服务安全性、保障运营质量及效率，以及进行广告投放与效果归因，我们会收集您的设备信息，包括：设备型号、操作系统版本、设备序列号（硬件序列号）、OAID、Android ID、IMSI（国际移动用户识别码）、设备ID、IMEI（国际移动设备识别码）、设备MAC地址、SIM卡序列号（ICCID）、软件安装列表（已安装应用列表）及运行中的进程信息、设备IP地址、网络信息（Wi-Fi状态、网络类型、网络运营商）。

2. 传感器信息：为识别您的设备横竖屏状态、保障视频播放体验，以及支持广告交互（如开屏摇一摇防误触、滑动操作），我们会调用设备的重力传感器、加速度传感器、陀螺仪传感器信息。

3. 日志信息：当您使用本应用时，我们会自动收集操作日志、崩溃日志，用于故障排查、安全审计与服务优化。

4. 使用行为信息：您的浏览记录、播放记录、点赞/收藏/分享行为、搜索关键词等，用于内容推荐与功能优化。

（三）权限调用说明

网络权限：加载视频、短剧、曲库、小说及广告内容（必需）。

存储权限（读取/写入外部存储）：视频缓存、离线下载、保存或上传图片（非必需）。

相机权限：拍摄/上传头像、扫码（非必需）。

读取电话状态（设备状态）：获取设备标识符，用于广告投放、反作弊与安全风控，由第三方广告SDK调用（非必需）。

账户权限：账号同步（非必需）。

修改系统设置：保存亮度等播放设置（非必需）。

闪光灯/震动：手电筒、通知提醒（非必需）。

您拒绝提供非必要权限，不影响您使用本应用的基本功能。

（四）用户画像与个性化推荐

我们可能基于您的浏览、播放行为进行用户画像，用于个性化内容推荐与广告投放。您可以在本应用「我的 → 设置」中关闭个性化推荐；关闭后，我们将不再将您的使用行为信息用于个性化推荐。

（五）Cookie 和同类技术

本应用不通过浏览器使用 Cookie。为实现登录状态保持、广告投放与频次控制，我们及第三方SDK可能使用本地缓存（如SharedPreferences、本地文件）存储OAID等设备标识符。

（六）收集规则说明

1. 我们仅出于本政策声明的目的收集、使用您的个人信息，不收集与本应用功能无关的信息；

2. 我们不会因您拒绝提供非必要个人信息而拒绝您使用基本功能；

3. 若收集、使用信息的目的、方式、范围发生变更，我们将征得您的同意后方按新目的处理。

二、我们如何共享、转让、公开披露您的个人信息

（一）共享：我们仅在本政策声明的目的范围内，与第三节所列第三方SDK共享必要的最小范围个人信息，用于广告投放、统计分析、安全风控等功能；共享的个人信息类型、接收方及目的均在本政策第三节载明。除此之外，我们不会与任何无关第三方共享您的个人信息。

（二）转让：我们不会将您的个人信息转让给任何公司、组织和个人，但以下情况除外：获得您明确同意；在涉及合并、收购或破产清算时，如涉及个人信息转让，我们会要求新的持有者继续受本政策约束。

（三）公开披露：我们仅会在以下情况下公开披露您的个人信息：获得您明确同意；基于法律法规、诉讼或行政、司法机关的强制性要求。

（四）征得授权同意的例外：根据法律法规规定，以下情形中收集、使用、共享、转让、公开披露个人信息无需征得您的同意：与国家安全、国防安全直接相关的；与公共安全、公共卫生、重大公共利益直接相关的；与犯罪侦查、起诉、审判和判决执行等直接相关的；出于维护您或其他个人的生命、财产等重大合法权益但又很难得到本人同意的；您自行向社会公众公开的个人信息；从合法公开披露的信息中收集的个人信息；法律法规规定的其他情形。

四、信息的存储与保护

1. 存储地点：您的个人信息将存储于中华人民共和国境内。

2. 存储期限：我们仅在本政策所述目的所必需的最短期限内保存您的个人信息；账号注销后，我们将在15个工作日内删除或匿名化处理您的个人信息，法律法规另有规定的除外。

3. 安全措施：我们采用符合行业标准的安全技术和管理措施保护您的个人信息，包括HTTPS加密传输、访问权限控制、日志审计等。

4. 安全事件：若发生个人信息安全事件，我们将按照法律法规要求及时告知您相关情况，采取补救措施，并依法承担相应责任。

五、您的权利

1. 查询、更正、删除：您可以在本应用「我的 → 设置」中查询、更正您的账号信息；如您要求删除个人信息，可以通过第七条所述方式联系我们。

2. 撤回同意：您可以在手机系统设置中关闭相应权限以撤回授权；撤回同意不影响撤回前基于同意已进行的个人信息处理。

3. 注销账号：您可以在本应用「我的 → 设置 → 注销账号」中，阅读并同意《账号注销协议》后提交注销申请；我们将在15个工作日内完成账号注销，并删除或匿名化处理您的个人信息。

4. 关闭个性化推荐：您可以在本应用「我的 → 设置」中关闭个性化推荐。

5. 响应时限：我们将在15个工作日内响应您行使上述权利的请求；法律法规另有规定的除外。

六、未成年人保护

本应用仅面向年满18周岁的成年人提供，我们不会主动收集未成年人的个人信息。若您发现未成年人未经监护人同意使用了本应用并提供了个人信息，请通过第七条所述方式联系我们，我们将尽快核实并删除相关个人信息。针对不满14周岁的儿童，我们制定了《儿童个人信息保护规则》，您可在本应用内查阅。
