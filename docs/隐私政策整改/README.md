# 隐私合规整改 —— 隐私政策内容同步（问题：报告4.1 违规收集个人信息 场景2/3/5/6）

> 依据：`docs/报告.pdf`（应用宝·腾讯安全大数据实验室《隐私合规检测报告》，检测时间 2026-08-21）
> 整改范围：**仅文案内容**（场景3、场景6 的整改要求）。场景2、场景5 的"同意前 SDK 提前初始化"属于代码整改，另行处理。

## 报告要求（原文归纳）

- 场景3：APP 收集的设备 MAC 地址、软件安装列表未在隐私政策中说明 → **必须明示目的、方式、范围，并使用规范名称**；
- 场景6：SDK 收集的设备 MAC 地址、软件安装列表未说明 → **必须准确写明每个 SDK 的名称和对应收集的个人信息**；
- 报告同时给出整改模板（场景4 示例）："为识别您的设备ID并预防恶意程序及反作弊……我们会收集您的设备信息（设备序列号、OAID、Android ID、IMSI、设备ID、MAC地址、序列号、已安装APP信息或运行中的进程信息）"；传感器信息需写明"为识别设备横竖屏状态……调用重力、加速度传感器"。

## 本次补齐的关键内容（对照报告）

1. **设备信息**：明确列出 设备序列号、OAID、Android ID、IMSI、设备ID、IMEI、设备MAC地址、SIM卡序列号(ICCID)、**软件安装列表（已安装应用列表）**及运行中的进程信息、设备IP地址、网络信息；
2. **传感器信息**：重力传感器、加速度传感器、陀螺仪传感器（目的：横竖屏识别、播放体验、广告交互）；
3. **第三方 SDK 清单**（按报告第6/7页实际检出结果）：Taku(TopOn)、优量汇、百度广告、穿山甲、百度移动统计、火山引擎设备安全、百度音视频处理MCP、fastjson、MSA(移动安全联盟OAID) —— 每个写明运营主体、用途、收集信息、隐私政策链接；
4. **敏感个人信息加粗+下划线**显著标识（IMEI、MAC地址、身份证等）；
5. **注销账号 15 个工作日**时限说明；
6. **个性化推荐开关**说明（App 内「我的→设置」可关闭）；
7. 声明"本应用不收集通讯录、短信、通话记录、精准位置"（报告场景模板中提及这些类型仅为通用模板，本 App 实际未收集）。
