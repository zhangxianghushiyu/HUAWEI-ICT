             |

  - 前端调用点约 38 处，封装在 common/taku-sdk.js
  -
  原生插件：nativeplugins/TakuAdsNativePlugin/、uni_modules/TakuAdsNativePlugin/

  2. 迁移核心原则

  - 广告位数量不变、业务逻辑不变、只换 SDK 调用层

  3. 主要改造项

  - 新建 common/uniad-sdk.js 替代 common/taku-sdk.js
  - 删除 Taku 原生插件目录
  - manifest.json 移除 TakuAdsNativePlugin
  - 各页面把 TakuAds.xxx 替换为 uni.createRewardedVideoAd /
  uni.createInterstitialAd / uni.createBannerAd
  - App.vue 开屏改用 <ad-splash> 或 uni-ad 开屏 API
  - 更新 androidPrivacy.json 和隐私政策 HTML，去掉 Taku/TopOn

  4. 后端需要同步

  - /publicize/taKuResultByTransId 等接口需要改为 uni-ad 格式
  - 建议新建 t_uniapp_ad_config 表存 adpid

  5. 推荐实施步骤（6 个 Phase）

  1. 环境准备：uni-ad 后台创建 5 个广告位，拿 adpid
  2. 封装层替换：写 common/uniad-sdk.js
  3. 逐个替换：激励视频 → 插屏 → Banner → 开屏
  4. 清理与配置：删插件、改 manifest、更新隐私政策
  5. 后端接口迁移
  6. 回归测试

  6. 风险与兜底

  - uni-ad 后台无填充风险，建议保留 Taku 分支可回滚
  - 激励视频无服务端验证，需后端增加反作弊
  - 开屏组件在离线基座可能不支持
